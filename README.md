# Forbidden Layer

Personal website for cybersecurity, AI, science and exploration.

## Local development

Open `index.html` in a browser, or use VS Code Live Server.

## Structure

- `index.html` — main page and sections
- `css/style.css` — layout, responsive design and themes
- `js/main.js` — dark/light mode and navigation state
- `assets/hero.png` — landing-page artwork

## GitHub Pages

After pushing the repository to GitHub:

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.
4. Save.
5. Add `forbiddenlayer.com` as the custom domain.
6. Configure the DNS records at GoDaddy using GitHub's current Pages instructions.

Do not expose server credentials, API keys or private information in this repository.
